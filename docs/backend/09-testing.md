## ۲. نام‌گذاری و جا

- تست کنار کد: `*.test.ts` (واحد)؛ `test/integration/**/*.int.test.ts` (یکپارچگی).
- **نام هر تست با شناسهٔ AC شروع می‌شود** (`CLAUDE.md` ۶ بند ۴)؛ تستی که AC ندارد با شمارهٔ بخش سند: `'AC-AP-03 — +16 پس از مرحلهٔ اول به stage2 می‌رود'`، `'05 ۹ — دو تأیید هم‌زمان: دومی ۴۰۹'`.
- تست‌های فرانت که الان روی ماک سبزند (مثال مرجع، قالب‌ها، MSP، گزارش مدیریتی، جستجو) **به بک‌اند منتقل می‌شوند** با همان نام؛ ماک فرانت مرجع رفتار بوده و حالا سرور باید همان عدد را بدهد.

## ۳. دروازهٔ مثال مرجع

`computation/domain/formulas/reference-example.test.ts`:
BAC=1000، PV=550، EV=490، AC=520، پیشرفت فیزیکی واقعی 49.2 و برنامه‌ای 55، CPI=0.9423، SPI=0.8909، EAC=1,061.2245 (`CLAUDE.md` ۳ بند ۱۱).

به‌علاوهٔ یک تست یکپارچگی سرتاسری: seeder مثال مرجع ← تأیید آیتم‌ها از API ← کار `compute.project` ← خواندن `GET /v1/projects/:id/progress` ← همان اعداد. **تا این دو سبز نشوند، کار مرحلهٔ ۴ نقشهٔ راه شروع نمی‌شود.**

## ۵. تست قرارداد

| تست | چه می‌کند |
|---|---|
| **endpoint ↔ کد دسترسی** | همهٔ مسیرهای ثبت‌شدهٔ Nest را می‌گیرد؛ هر مسیر غیر `@Public` دقیقاً یک `x-permission` دارد و کدش در `packages/shared/permissions.ts` هست؛ و هر کد کاتالوگ دست‌کم یک مسیر یا دلیل ثبت‌شده دارد (F01 ۵.۲) |
| **حذف مبلغ** | برای هر پاسخ دارای `x-amount-fields`، درخواست با کاربر بی‌`cbs.view_amounts` هیچ‌کدام از آن کلیدها را ندارد (`access-control.md` ۵.۵) |
| **OpenAPI تازه** | `openapi.json` تولیدی با فایل commit‌شده یکی است |
| **سازگاری با فرانت** | برای ماژولی که سوئیچ `hybridQuery` شده، پاسخ سرور روی seed نگین با شکل خروجی ماک فرانت مقایسه می‌شود (کلیدها و نوع‌ها، نه مقدار) |

**ساخته شد (برش ۲۰، 1405/08/27؛ code-mapping ۳.۵.۵۹):** سه تست اول در `test/integration/contract.int.test.ts` (کد بی‌مسیر فقط با دلیل در `UNROUTED`)؛ تازه کردن سند با `pnpm --filter @projeyar/backend run openapi:emit`. سازگاری با فرانت یک بار پیش از حذف ماک‌ها اجرا شد و ابزارش با ماک‌ها رفت. به‌جای `import/no-cycle`، `src/modules/module-graph.test.ts` یال تازه درون چرخهٔ ماژول‌ها را رد می‌کند.

## ۶. دادهٔ تست

- سازنده‌های داده در `test/fixtures` (`aProject().withWbs(…).build(em)`)؛ هیچ تستی به دادهٔ تست دیگر وابسته نیست.
- هر فایل تست یکپارچگی schema خودش (یا تراکنش بازگشتی برای هر تست) را دارد تا تست‌ها موازی اجرا شوند.
- `Clock` جعلی برای مهلت‌ها و تیک‌ها؛ هیچ `sleep`.
- seederهای `05` ۱۳ هم در تست سرتاسری استفاده می‌شوند.

## ۷. CI

به ترتیب، هر کدام شکست = توقف:

1. `pnpm install --frozen-lockfile`
2. `typecheck` (`tsc --noEmit`) — بک‌اند، فرانت، shared
3. `lint` — صفر خطا
4. `test` — واحد
5. `test:integration` — با Testcontainers (فعلاً PostgreSQL محلی با `TEST_DB_ADMIN_URL`؛ README ۶)
6. `test:contract` + بررسی تازگی `openapi.json` و نمودارهای گردش کار
7. `pnpm audit --audit-level high`
8. ساخت image
