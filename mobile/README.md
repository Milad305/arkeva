
## آزمون دستی روی گوشی (rules ۱۳)

تست خودکار منطق را می‌پوشاند؛ این‌ها به گوشی واقعی نیاز دارند:

| معیار | گام | انتظار |
|---|---|---|
| AC-FA-01 | حالت پرواز ← ثبت یک فعالیت با ۲ عکس ← بازبینی ← «ذخیره در صف ارسال» ← خاموش کردن حالت پرواز | گزارش بی‌دخالت ارسال شود؛ M09 خالی شود؛ M10 «در انتظار» |
| AC-FA-01 | وسط ارسال عکس Wi‑Fi را قطع و وصل کنید | گزارش تکراری در وب ساخته نشود |
| AC-FA-03 | عکس بزرگ با اتصال ضعیف؛ قطع وسط بارگذاری | پس از وصل، ادامه از همان پارچه (لاگ سرور) |
| AC-FA-04 | M07 | هیچ دکمه یا مجوز گالری نیست؛ عکس در وب مهر کامل دارد (تاریخ شمسی، مختصات، دقت، داخل/خارج کارگاه، کد فعالیت، نام) |
| AC-FA-05 | برنامهٔ Mock Location در گزینه‌های توسعه‌دهنده | آیتم در صندوق ناظر با پرچم `mock_location` |
| AC-FA-08 | پس از هر همگام‌سازی | W23 تعداد صف و قدیمی‌ترین مورد را درست نشان دهد |
| workmanager | اپ را ببندید با صف پر | حداکثر ۱۵ دقیقه پس از اتصال ارسال شود |
| یادآوری | بی گزارش امروز تا ساعت یادآوری پروژه (پیش‌فرض ۱۷:۰۰) | اعلان محلی «گزارش امروز» در همان ساعت؛ M03 «مهلت تا …» |
